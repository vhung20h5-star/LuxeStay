# ✨ LuxeStay — Nền Tảng Đặt Phòng Khách Sạn & Homestay Du Lịch

**LuxeStay** là ứng dụng web đặt phòng khách sạn, resort ven biển, villa và homestay nghỉ dưỡng hiện đại tại Việt Nam, được thiết kế với giao diện sang trọng (Glassmorphism) và hiệu ứng chuyển động mượt mà.

## 🚀 Công nghệ sử dụng

- **Framework**: Next.js 16 (App Router)
- **Ngôn ngữ**: TypeScript
- **Styling**: Tailwind CSS v4 + PostCSS
- **Animation**: Framer Motion & Canvas Confetti
- **Icons**: Lucide React

## 🌟 Tính năng chính

- **Tìm kiếm thông minh**: Tìm theo điểm đến nổi bật (Đà Lạt, Phú Quốc, Sa Pa, Đà Nẵng, Hội An, Ninh Bình...), chọn lịch trình nhanh, tùy chỉnh số lượng khách & phòng.
- **Lọc đa tiêu chí & Sắp xếp**: Lọc theo danh mục trải nghiệm (Săn mây, Sát biển, Vintage Homestay, Hồ bơi vô cực, Glamping...), khoảng giá, đánh giá sao, tiện nghi và chính sách hủy phòng miễn phí.
- **Thẻ phòng tương tác**: Trình chiếu ảnh (Photo Carousel) trực tiếp trên thẻ, nút lưu danh sách yêu thích (Wishlist Drawer) lưu trữ trên `localStorage`.
- **Chi tiết chỗ nghỉ & Tính giá tự động**: Xem album ảnh, thông tin chủ nhà (Superhost), tiện ích, đánh giá thực tế và bảng tính chi phí theo số đêm lưu trú.
- **Luồng đặt phòng & Xác nhận vé điện tử**: Nhập thông tin khách, chọn phương thức thanh toán (MoMo, VNPAY, Thẻ quốc tế, Tiền mặt), sinh mã đặt phòng kèm hiệu ứng pháo hoa và hỗ trợ in/lưu vé PDF.

## 🛠️ Cài đặt & Khởi chạy

```bash
# 1. Cài đặt dependencies
npm install

# 2. Chạy môi trường phát triển (Development)
npm run dev

# 3. Kiểm tra lỗi cú pháp & kiểu dữ liệu
npm run lint

# 4. Build bản Production
npm run build
npm run start
```

Mở trình duyệt tại [http://localhost:3000](http://localhost:3000) để trải nghiệm.
